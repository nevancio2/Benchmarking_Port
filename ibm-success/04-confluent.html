What IBM Did — The Confluent Acquisition

IBM Now Owns the World's Leading Real-Time Data Streaming Platform

In March 2026, IBM completed its acquisition of Confluent — positioning real-time data as, in IBM's own words, "the engine of enterprise AI and agents." This acquisition is directly relevant to NCDOT because Confluent is the exact technology needed to solve NCDOT's fragmented legacy data architecture.

Confluent is built on Apache Kafka, the industry standard for high-throughput real-time data streaming, and Apache Flink, which enables stream processing and complex event handling. Together, they provide a unified platform to stream, connect, process, and govern data across any combination of legacy systems — without those systems needing to be replaced or modified.

IBM has already published documented approaches for modernizing mainframes using Confluent on IBM zSystems. The Royal Bank of Canada (RBC) is among the published reference case studies — demonstrating that Confluent-on-IBM works at the scale and regulatory complexity comparable to a large public-sector transportation agency.

Real-time data flows from every NCDOT source — toll gantries, ferry terminals, transit vehicles, highway sensors — into a single Kafka event stream. No application needs to be rebuilt.

Connect & Process

Confluent connectors integrate with NCDOT's existing legacy applications. Apache Flink processes events in real time — enabling complex queries like "how does a highway incident affect ferry demand right now?"

Govern & Act

IBM's governance layer ensures data quality, lineage, and security across all streams. IBM watsonx AI consumes the governed data stream to deliver predictive analytics, dynamic routing, and revenue optimization.

This is the Technical Foundation NCDOT's Entire Modernization Strategy Requires

Without a data streaming layer, every other IBM case study in this document remains theoretical. Confluent is what makes the IRS-style incremental modernization, the VA-style unified visibility, and the Smart City AI capabilities all simultaneously achievable for NCDOT.

  • Toll integration: Real-time NC Turnpike transaction data flowing alongside transit ridership — no changes to NCTA's toll collection software
  • Ferry operations: Live GPS, passenger counts, and vessel status streamed in real time to NCDOT's unified platform
  • Transit operators: GoRaleigh, GoTriangle, CATS, GoDurham all streaming data through the same Confluent layer without replacing any operator system
  • Highway sensors: Traffic camera and sensor data feeding the same platform as transit and ferry data for true cross-modal intelligence

NCDOT's Three Immediate Benefits from Confluent

  • Unified real-time reporting: A single dashboard showing toll revenue, transit ridership, ferry capacity, and highway congestion — all updating live, available to NCDOT leadership without any system replacement
  • Zero legacy disruption: Every NCDOT regional operator keeps their current system. Confluent connectors extract and stream data without touching source applications — reducing implementation risk to near zero
  • AI readiness on day one: Once the Confluent streaming layer is operational, IBM watsonx can immediately begin training on the unified data stream — delivering demand forecasting, anomaly detection, and dynamic resource allocation within months, not years
